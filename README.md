## 发表论文

### 2026

#### Variations in the Milky Way's Stellar Mass Function at [Fe/H] < -1

**arXiv:** [2601.19522](https://arxiv.org/abs/2601.19522)

**摘要：**
我们首次确定了对低质量恒星（0.2-0.5 M☉）在[Fe/H] < -1的银河系恒星质量函数（MF）。基于Gaia DR3 BP/RP (XP)光谱的金属丰度估计，我们选择了约53,000颗具有晕状轨道且光谱金属丰度[Fe/H] < -1的恒星作为贫金属样本。对于-1.5 < [Fe/H] < -1，我们发现MF在0.5 M☉以下呈现出"底重"幂律斜率α ≈ -1.6。我们尝试性地发现，即使在更低金属丰度下，MF变得极底轻，接近α ≈ 0的近平坦幂律斜率，这意味着低质量恒星严重缺乏。这种金属丰度依赖的变化对所采用的恒星演化模型不敏感。这些结果表明，银河系低质量MF并非普适，在贫金属区间存在变化。对M < 0.5 M☉和[Fe/H] < -1.5区间内XP金属丰度的进一步校准对于验证这些试探性低金属丰度趋势至关重要。

**作者：** Jiadong Li, Hans-Walter Rix, Yuan-Sen Ting, Yu-Ting Wang, Szabolcs Mészáros, Ilija Medan, Chao Liu, Zhiqiang Yan, Peter J. Smith, Dan Qiu, Alexandre Roman-Lopes, Gregory M. Green, Danny Horta, Zachary Way, Tadafumi Matsuno, Stefano Souza, José G. Fernández-Trincado

**发表时间：** 2026年1月27日

**状态：** 已接受发表在 *The Astrophysical Journal Letters* (ApJL)
